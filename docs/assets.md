# Artwork and asset inventory

The source asset tree contains **27 files**, down from 204. The audit removed 177 unused or duplicate files (about 1.86 MB); retained files total 599,398 bytes. This reduces source/package artwork size, not necessarily RAM: unused files were not being decoded by the widget.

| Path | Retained | Use |
| --- | ---: | --- |
| `Assets/Brand` | 3 | Editable SVG, generated PNG for window icons, embedded/application ICO. Different formats serve different purposes. |
| `Assets/WeatherGadget` | 22 | Ten compact and twelve expanded backgrounds, including loading and all mapped weather/day/night states. |
| `Assets/WinPrognoza/slike` | 2 | Compact sunny and partly-cloudy backgrounds used by the legacy themes. |

Removed: the duplicate OriginalCards tree, unused WinPrognoza icons/previews, numbered gadget symbols, unused moon phases and colour variants, old gadget UI buttons/state indicators, GIF spacer and unused DPI controls. All original files in the separate XWidget installation were left untouched.

Every retained weather bitmap is exercised by the weather-code/day/size tests. The published weather payload must exactly match those reachable files and contain no byte-identical duplicates. Publishing clears obsolete output artwork so previously copied files do not remain in a new package; the running package must be closed first.

Modern and Classic use retained legacy PNG scenes. Aurora, Paper, Sunset, Nordic and Forest use vector scenes generated by the theme renderer. Branding source is retained for icon regeneration.
